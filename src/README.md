# DataFrameReporter

## О чём проект

`DataFrameReporter` — небольшой инструмент для быстрого получения
сводного отчёта по датафрейму pandas. Класс решает задачу
**унифицированной первичной диагностики данных** перед анализом:
позволяет за один вызов увидеть размер таблицы, количество
и долю дубликатов и пропусков, а также получить базовую
статистику по всем столбцам.

Класс полезен при работе с новыми наборами данных — когда нужно
быстро оценить «здоровье» таблицы: сколько в ней строк и столбцов,
есть ли дубликаты, сколько пропущено значений. Формат вывода чисел
(обычных и процентных) настраивается через параметры конструктора,
что позволяет адаптировать отчёт под конкретные требования —
например, для отображения в логах, в отчёте или в Jupyter Notebook.

## Установка окружения

### 1. Клонирование репозитория

```bash
git clone https://github.com/PyroPonya/mle-razrabotka-v-ide.git
cd mle-razrabotka-v-ide
```

### 2. Создание виртуального окружения

**Windows:**

```bash
python3 -m venv venv
. venv/Scripts/activate
```

**Linux / macOS:**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

Виртуальное окружение готово — все библиотеки (`pandas`, `numpy`
и их зависимости) установлены.

## Запуск

Запускать проект следует **из корня репозитория**, чтобы относительные
пути к файлам данных (`./data/payments.csv`) были корректными:

```bash
python main.py
```

В результате в консоль будут выведены два отчёта по данным
`data/payments.csv`:

1. **Отчёт в формате 1** — с точностью `float_format='0.02f'`
   и `percent_format='0.03%'`, без расширенной статистики.
2. **Отчёт в формате 2** — с точностью `float_format='0.03f'`,
   `percent_format='0.01%'` и включённой опцией `include_all=True`
   (в вывод добавляется статистика по всем столбцам через
   `df.describe(include='all')`).

## Параметры `DataFrameReporter`

| Параметр         | По умолчанию | Назначение                             |
| ---------------- | ------------ | -------------------------------------- |
| `float_format`   | `'0.05f'`    | формат вывода чисел с плавающей точкой |
| `percent_format` | `'0.02%'`    | формат вывода процентов                |
| `include_all`    | `False`      | выводить ли `describe(include='all')`  |

Метод `show_report(df, title=None)` принимает датафрейм и
необязательный заголовок. Если `title` не указан, заголовок
не выводится.
